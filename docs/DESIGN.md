# 设计说明

所有样式都在 `index.html` 开头的 `<style>` 里，顶部 `:root` 是设计变量（颜色、圆角、字号、动效时长），改一处全站生效。没有前端框架，也没有打包工具。

## 整体思路「一张稿纸 + 一位搭档」

- **三块各管一件事**：左边找稿子、建稿子；中间只有文章；右边按写作流程帮忙。
- **记号是“墨点”**：导航和流程的图标都带一个实心墨点（`js/ui.js` 里 class="ink"），选中时变成品牌蓝并弹一下；AI 在干活时墨点会呼吸；新批注像荧光笔一样从左往右划过去。
- **新建**：左栏顶上是写作库名字和“新建笔记 / 让 AI 写一篇”两行；机器人图标会眨眼，笔划过会留下一道墨迹。
- **状态**：左栏底部是状态列表（带颜色点和篇数），点一下筛选；把笔记拖上去就改成那个状态。
- **右栏是一条流程线**：写作 → 批注 → 评分 → 配图 → 发布，后面是链接、版本两个工具。做完的步骤墨点变蓝，线一段一段被墨水填满；下面一行说明当前这一步。
- **配图在右栏**：“配图”一步里排配图、复制提示词、直接画、让 AI 检查；在正文里选中一段，工具条上点“配图”，只给那一段配一张。
- **第一次用**：每个页面和每一步第一次打开时，会高亮一块区域、弹一张卡片讲怎么用（`js/tour.js`）；页面头部有一条指引栏，关掉后还能点“怎么用”再看。
- **颜色**：灰阶为主；蓝色只给主操作、链接和墨点；配置项选中是白底描边，筛选和开关是灰 / 深色。字号只有 12 / 14 / 17 / 28。
- **阴影代替线**，留白比上一版多一档。不再用超椭圆圆角（在 Electron 里会留下残影）。

## 动效

只动 `transform` 和 `opacity`，只用 ease-out；滑动的东西用 `cubic-bezier(.32, .72, 0, 1)`。系统开了“减少动态效果”时几乎全部关掉。

| 在哪 | 效果 |
|---|---|
| 分段控件、流程线、左侧导航、状态列表、心智档位 | 同一块底从旧选项滑到新选项（`js/ui.js` 里的 `U.glide`）。整组被重新渲染时也记得上次的位置，从那里滑过来 |
| 切换左侧页面 | 旧页 120ms 淡出，新页按导航方向从上或下错开 10px 进来，透明度先到位 |
| AI 面板切标签 | 内容从标签所在方向横着滑进来，逐块错开 30ms |
| 换一篇笔记 | 同一张稿纸，内容轻轻浮上来；新开的标签页弹出来 |
| 激素预设 | 不重新渲染，色条各自滑到新数值 |
| 评分 | 弧线从 0 长到分数，数字数上去，分项和“实际 vs 目标”的色条依次长出 |
| 选中文字 | 工具条从选区上方长出，点批注类型后原地展开成批注框 |
| 滑杆、开关、按钮 | 按下有反馈（放大、拉长、缩到 0.97），说明见 `js/ui.js` |

## 神经递质 / 激素、脑区

“人性”页最上面两张卡：

- **神经递质 / 激素**：多巴胺、催产素、皮质醇、血清素、去甲肾上腺素五根色条，表示读者读这篇时希望被激起的程度（50 是平常）。有“钩子型 / 陪伴型 / 预警型 / 干货型 / 正常节律”五个预设，下面一句话读出整体状态。每一项的作用、写法、红线都能展开改。
- **脑区 · 记忆住在哪**：脑干（世界之魂）、杏仁核（情绪核心）、海马体（编码索引）、前额叶（检索决策），表示这篇想被记在哪一层。

这里是默认值；写作面板的“读者的身体”卡可以给单篇单独调（只记改过的数）。两者都会写进每一次提示词；评分时 Claude 会估计实际激起的程度，在评分页和目标并排对比。

## 正文里的线是什么意思

两个开关各管一类标记：

**评分标记**（评分页“在正文里标出评分依据”）

| 样子 | 意思 |
|---|---|
| 红色波浪线 | 这段有问题 |
| 橙色实线 | 这段可以更好 |
| 绿色实线 | 这段写得好 |

**本地检查**（底栏“标出问题”，不用 AI，按“参数”页的规则实时检查）

| 样子 | 意思 |
|---|---|
| 橙色点状虚线 | 段落太长，超过当前平台的每段字数 |
| 橙色波浪线 | AI 味句式，比如“不是……而是……” |
| 红字粉底 `[需补证据：…]` | 占位，发之前要补上真实的证据或经历 |

另外，黄色荧光底是划线批注过的地方。
